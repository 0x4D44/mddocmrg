# Coverage Improvement Plan
**Date:** 2026-01-09
**Project:** mddocmrg

## Goal
Increase code coverage from the current low level (due to untested `main`) to >98%.

## Stage 1: Refactor for Testability
**Objective:** Decouple CLI logic from `std::process::exit` and `std::env::args`.
1.  Extract the body of `main` into a public function `run(args: Vec<String>) -> Result<(), Box<dyn std::error::Error>>`.
2.  Refactor `print_usage` to return a string or write to a passed writer (optional) or just be called by `run`.
3.  Ensure `run` returns errors instead of exiting, allowing `main` to handle the final exit code.

## Stage 2: CLI Integration Tests
**Objective:** Verify CLI argument parsing and high-level flow.
1.  Add a test module for CLI logic.
2.  Test `run` with `["prog", "-h"]` -> Should return Ok (or specific "Help" signal).
3.  Test `run` with `["prog"]` (no args) -> Should return Error.
4.  Test `run` with invalid patterns -> Should return Error.
5.  Test `run` with valid patterns -> Should generate `merged.txt`.

## Stage 3: Error Handling & Edge Cases
**Objective:** Cover hard-to-reach error paths.
1.  Create a test case with a corrupted DOCX (valid ZIP but invalid XML) to trigger the `Reader` error branch in `extract_text_from_docx`.

## Verification
After each stage, run `cargo llvm-cov --text` to monitor progress.
